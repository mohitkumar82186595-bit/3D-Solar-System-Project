# 3D-Solar-System-Project
🌌 Interactive 3D Solar System using HTML, CSS & JavaScript

I built an interactive Solar System animation completely from scratch using HTML, CSS and JavaScript — without Python or external image assets.

✨ Features:
☀️ Animated glowing Sun
🌍 Earth with continents & clouds
🌙 Interactive Moon orbit
🪐 Saturn with animated rings
🟤 Jupiter with atmospheric bands & Great Red Spot
☄️ Moving Comet
🪨 Dynamic Asteroid Belt
⭐ Animated Star Field
🌌 Milky Way effect
🔄 Real-time planetary orbit animations
⏸️ Pause / Play controls
⚡ Multiple animation speeds
🏷️ Planet labels
🖱️ Mouse parallax interaction
📱 Responsive design

This project was a great experiment in combining CSS animations, JavaScript DOM manipulation, orbital motion and visual effects to create a realistic-looking space experience directly in the browser.

💡 Tech Stack:
HTML5 | CSS3 | JavaScript | CSS Animations | DOM Manipulation

I'm continuing to build advanced frontend experiments and interactive UI projects to improve my skills and create visually engaging web experiences.
